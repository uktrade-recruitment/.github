## Purpose

The `uktrade-recruitment` GitHub organisation is exclusively for technical recruitment activities, including:

- Hosting technical challenges and exercises
- Sharing interview questions and supporting materials
- Giving candidates temporary access to repositories
- Reviewing code produced during interviews or assessments

It must not be used for project work, product development, proofs of concept, or ongoing experimentation, even where the work is fictional or not intended for production.

## Repository requirements

Repositories in this organisation must:

- Be created for a specific recruitment activity
- Be public only while candidates require access
- Contain only fictional or deliberately simplified code that does not replicate, connect to, or affect DBT services, products, or production codebases
- Not contain sensitive information, credentials, personal data, or internal service configuration

## Code security

The Code Security Framework does not need to be applied to repositories in this organisation, provided they meet the requirements above.

If a repository contains sensitive information, represents an existing DBT codebase, connects to an internal or production service, or is used for anything other than recruitment, it is outside the scope of this organisation. It must be moved to an appropriate organisation and have the required security controls applied.

## After the recruitment activity

Repository owners must:

1. Remove candidate access when the recruitment activity has finished.
2. Change the repository back to **internal visibility** after the interviews.
